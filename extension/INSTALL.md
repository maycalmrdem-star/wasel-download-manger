# تثبيت إضافة واصل للمتصفح

تدعم الإضافة Chrome وEdge وBrave، كما تدعم Firefox 128 أو أحدث بملف manifest خاص به. لا يوجد حاليًا مثبت تلقائي أو متجر مدمج؛ يتم تحميل الإضافة محليًا من مجلد المشروع.

## التحضير

1. ثبّت Node.js، وافتح الطرفية في مجلد المشروع.
2. شغّل `npm install` إذا لم تكن الاعتماديات مثبّتة.
3. شغّل `npm run build:ts`.
4. اترك المجلد `extension` كما هو؛ يحتوي `manifest.json` وملف JavaScript الناتج.
5. شغّل Wasel مرة واحدة باستخدام `npm start` حتى يسجل النظام مخطط `wasel://` ويظهر رمزه في علبة النظام.

يمكنك أيضًا فتح **إضافة المتصفح** من الشريط العلوي داخل Wasel لرؤية دليل مصور لكل متصفح ونسخ الأمر أو مسار الإضافة.

## Chrome وBrave

1. افتح `chrome://extensions` أو `brave://extensions`.
2. فعّل **Developer mode / وضع المطوّر**.
3. اضغط **Load unpacked / تحميل إضافة غير محزّمة**.
4. اختر مجلد `extension` داخل مجلد المشروع، وليس ملف `manifest.json`.
5. ثبّت الإضافة في شريط الأدوات لسهولة الوصول إليها.

## Microsoft Edge

1. افتح `edge://extensions`.
2. فعّل **Developer mode / وضع المطوّر**.
3. اختر **Load unpacked / تحميل غير مضغوط**، ثم اختر مجلد `extension`.

## Firefox

1. افتح `about:debugging#/runtime/this-firefox`.
2. اختر **Load Temporary Add-on...**.
3. من مجلد `extension` احتفظ بنسخة من manifest الحالي ثم نفّذ في PowerShell: `Copy-Item manifest.json manifest.chromium.json; Copy-Item manifest.firefox.json manifest.json`.
4. اختر ملف `extension/manifest.json`.
5. ملاحظة: التحميل المؤقت يزيل الإضافة عند إغلاق Firefox. للتثبيت الدائم يلزم توقيع حزمة XPI ونشرها أو توزيعها وفق متطلبات Mozilla. لاستعادة إعداد Chromium لاحقًا، نفّذ `Copy-Item manifest.chromium.json manifest.json`.

## الاستخدام

1. شغّل Wasel مرة واحدة حتى يسجل Windows عنوان `wasel://`.
2. افتح صفحة ويب واضغط أيقونة Wasel في شريط المتصفح؛ يظهر عنوان الصفحة ويمكنك تعديله ثم اختيار **Send to Wasel**.
3. لالتقاط التنزيلات من أزرار المواقع، فعّل **Send browser downloads to Wasel automatically** في نافذة الإضافة. عند الضغط على زر تنزيل يرسل الامتداد رابط HTTP/HTTPS إلى التطبيق ويوقف نسخة التنزيل في المتصفح؛ يعرض Wasel تأكيدًا قبل تنزيل الملف.
4. أوقف خيار الالتقاط في نافذة الإضافة للعودة إلى تنزيلات المتصفح المعتادة.

تطلب الإضافة صلاحيات `activeTab` و`downloads` و`storage`؛ تستخدم `downloads` لمعرفة التنزيلات الجارية وإيقافها عند تفعيل الالتقاط، وتستخدم `storage` لحفظ اختياره. لا تحقن سكربتات في الصفحات ولا ترسل بيانات التصفح لخادم. يقبل التطبيق روابط HTTP وHTTPS فقط، ويرفض بيانات الاعتماد المضمنة في الرابط. قد تفشل الروابط التي تعتمد على ملفات تعريف ارتباط المتصفح أو تسجيل الدخول أو حماية الموقع؛ عطّل الالتقاط لتنزيلها مباشرة في المتصفح.

بعد تحديث الإضافة، اضغط **Reload / إعادة التحميل** في صفحة إضافات المتصفح لقبول الصلاحيات الجديدة.

## علبة النظام وأزرار النافذة

- زر الإغلاق المخصص يخفي نافذة Wasel إلى علبة النظام قرب ساعة Windows؛ لا ينهي التنزيلات.
- انقر رمز Wasel قرب الساعة لإظهار النافذة. قائمة الرمز تتيح إيقاف/استئناف كل التنزيلات أو إنهاء التطبيق فعليًا.
- أزرار التصغير والتكبير/الاستعادة مخصصة وتتغير ألوانها مع الثيم. دبل-كليك على مساحة شريط العنوان يبدّل التكبير والاستعادة.

## تحديث واصل

تتحقق النسخة المثبّتة من إصدارات GitHub دوريًا وتحمل التحديث في الخلفية. لأن المستودع خاص، يجب ضبط متغير المستخدم `GH_TOKEN` في Windows ليتمكن التطبيق من قراءة الإصدار؛ أنشئ fine-grained token بصلاحية `Contents: Read-only` لهذا المستودع فقط. لا ترسل الرمز إلى أحد ولا تحفظه داخل ملفات المشروع. يتولى GitHub Actions إنشاء مثبت Windows ومرفقات التحديث تلقائيًا عند دفع وسم `v*`.

لإضافة روابط بدون فتح مربع الإضافة، اسحب رابط HTTP/HTTPS أو مجموعة روابط وأسقطها فوق نافذة Wasel؛ تبدأ التنزيلات مباشرة. أما الروابط التي تصل من بروتوكول خارجي فتظل تتطلب تأكيدًا قبل بدء التنزيل.

## استكشاف الأخطاء

- إذا لم يفتح Wasel، شغّل التطبيق مرة واحدة عبر `npm start` وتأكد أن مجلد البناء يحتوي `extension/link-protocol.js`.
- بعد تغيير ملفات الإضافة أو إعادة بناء TypeScript، اضغط **Reload / إعادة التحميل** في صفحة إضافات المتصفح.
- Safari غير مدعوم في هذه الحزمة؛ يحتاج Web Extension مخصصًا وتوقيعًا وتوزيعًا عبر Apple.
