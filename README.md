# واصل — مدير التحميلات

تطبيق سطح مكتب لإدارة التنزيلات، مبني بـ Electron وNode.js. يحافظ على لوحة القوائم والتصنيفات والجدول وشريط الحالة، مع أسطح أكثر وضوحًا وأيقونات SVG موحدة، ومظهر داكن افتراضي وخيار فاتح وRTL. التصميم أصلي ومستوحى من فئة برامج إدارة التنزيلات دون نسخ أصول تجارية.

## التشغيل

1. ثبّت Node.js 20 أو أحدث.
2. شغّل `npm install`.
3. شغّل `npm start`.

يقوم أمر التشغيل ببناء جزء TypeScript المشترك تلقائيًا.

لبناء مثبت Windows محليًا شغّل `npm run build:win`. يبحث التطبيق المثبّت تلقائيًا عن تحديثات GitHub كل ست ساعات، وينزّلها في الخلفية ثم يعرض إشعارًا لإعادة التشغيل والتثبيت.

لأن مستودع GitHub **خاص**، يحتاج التطبيق المنشور رمز GitHub شخصيًا لقراءة الإصدارات. أنشئ fine-grained token للمستودع بصلاحية **Contents: Read-only** فقط، ثم أضفه إلى متغير المستخدم `GH_TOKEN` في Windows وأعد تشغيل واصل. لا تضع الرمز في ملفات المشروع أو إعدادات الإصدار. ينشئ GitHub Actions ملفات التثبيت عند دفع وسم إصدار مثل `v1.1.0`، باستخدام `GITHUB_TOKEN` المؤقت للنشر.

بعد استنساخ المشروع وضبط `origin` على مستودعك الخاص، انشر هذا الإصدار هكذا: `git tag v1.1.0` ثم `git push origin v1.1.0`. يتطلب بناء النسخة التالية تحديث `version` في `package.json` والوسم معًا.

## الوظائف الحالية

- إضافة رابط واحد أو عدة روابط HTTP/HTTPS، وتحديد اسم الملف ومجلد الحفظ، أو إضافة التنزيلات إلى قائمة الانتظار.
- تنزيلات متزامنة قابلة للضبط من 1 إلى 10، وإيقاف مؤقت/استئناف مع حفظ البيانات الجزئية بامتداد `.part`.
- جدول بفرز حسب الاسم والحالة والحجم والسرعة والتاريخ، وتحديد متعدد، بحث، تصنيف، وقائمة سياقية.
- نافذة تقدم مباشرة تعرض الحالة والسرعة والحجم والوقت المتبقي ومعلومات الملف.
- واجهة بـ17 لغة، تشمل العربية والإنجليزية والفرنسية والإسبانية والروسية والألمانية والإيطالية والبرتغالية والصينية واليابانية والكورية والتركية والهولندية والبولندية والأوكرانية والهندية والإندونيسية. تحفظ اللغة المختارة مع الإعدادات؛ النصوص التي لم تترجم في لغة ما تستخدم الإنجليزية بدلًا من إظهار نصوص غير مترجمة.
- تغيير المظهر الفاتح/الداكن، استيراد/تصدير مكتبة التنزيلات، والجدولة لبدء التنزيلات أثناء بقاء التطبيق مفتوحًا.
- فتح الملفات ومجلداتها، نسخ الرابط/المسار، السحب والإفلات للرابط، واختصارات لوحة المفاتيح.
- إسقاط رابط أو مجموعة روابط HTTP/HTTPS على النافذة يضيفها إلى القائمة ويبدأ التنزيل فورًا، من دون حوار إضافي.
- إشعارات تحديث تلقائي آمنة من إصدارات GitHub الخاصة، مع خيار إعادة التشغيل والتثبيت بعد الموافقة.
- إضافة رابط من امتداد المتصفح؛ لا يضيف التطبيق الرابط إلى المكتبة إلا بعد تأكيد المستخدم داخل التطبيق.
- تحويل تنزيلات HTTP/HTTPS من المتصفح إلى واصل اختياريًا عبر الامتداد؛ يظهر طلب تأكيد قبل بدء كل تنزيل، ويمكن إيقاف الالتقاط من نافذة الامتداد. يتطلب الامتداد صلاحيات `downloads` و`storage`.
- أزرار نافذة مخصصة ومتجاوبة مع المظهر الفاتح والداكن؛ زر الإغلاق يخفي واصل في علبة النظام قرب الساعة، وتبقى التنزيلات مستمرة. تتيح قائمة علبة النظام فتح التطبيق وإيقاف التنزيلات أو استئنافها وإنهاء التطبيق.
- يسمح اختيار مجلد الحفظ بجذر القرص إذا كان موجودًا؛ لا يحاول التطبيق إنشاء الجذر، وتبقى صلاحيات الكتابة محكومة بصلاحيات حساب Windows.

## امتداد المتصفح

يوجد امتداد WebExtensions في `extension/` لمتصفحات Chrome وEdge وBrave وFirefox 128 أو أحدث. لخطوات التثبيت المفصلة والرسوم التوضيحية لكل متصفح، اختر **إضافة المتصفح** في الشريط العلوي داخل التطبيق، أو افتح دليل [تثبيت إضافة المتصفح](./extension/INSTALL.md). يقرأ الامتداد عنوان التبويب عند فتحه. عند تفعيل خيار الالتقاط، يراقب عناصر التنزيل في المتصفح، ويوقف تنزيل HTTP/HTTPS الذي يلتقطه ثم يرسل رابطه إلى واصل؛ يعرض التطبيق طلب تأكيد قبل بدء التنزيل. قد لا تعمل الروابط التي تتطلب ملفات تعريف ارتباط أو جلسة تسجيل دخول المتصفح مباشرةً داخل واصل. يمكن إيقاف الالتقاط من نافذة الامتداد. Safari غير مشمول؛ يحتاج حزمة وتوقيعًا وتوزيعًا منفصلًا من Apple.

أيقونة التطبيق في `assets/wasel.ico`، والنسخة المتجهية في `assets/wasel.svg`. تتضمن ملفات بناء Windows إعداد الأيقونة من أجل Electron Builder؛ وتستخدم نافذة Electron الأيقونة نفسها مباشرة.

## TypeScript والأيقونات

توجد معالجة رابط الامتداد والتحقق من بروتوكوله بنوعيات صارمة في `src/link-protocol.ts`، وتُبنى إلى `extension/link-protocol.js` بواسطة `npm run build:ts`. يستخدمها كل من التطبيق والامتداد. الأيقونات المركزية معرفة في `src/icons.js`، وقواعدها في `src/icons.css`، مع تحسينات التخطيط في `src/ui-enhancements.css`.

## اللغات وبيانات المطوّر

توجد موارد الواجهة في `lang/` بملف JSON مستقل لكل لغة (`ara.json`, `eng.json`, `fra.json` وغيرها). أضيفت أسماء اللغات في قائمة إعدادات الواجهة، ويُضبط اتجاه المستند تلقائيًا إلى RTL للعربية وإلى LTR للغات الأخرى.

## حدود التنفيذ

محرك التنزيل يدعم HTTP وHTTPS فقط، وليس FTP أو تنزيل HTTP متعدد الأجزاء المتوازية بعد. الاستئناف يعتمد على دعم الخادم لطلبات HTTP Range؛ إذا لم يدعمها يبدأ التنزيل من جديد بدل إلحاق بيانات غير سليمة. الجدولة الحالية مؤقتة للجلسة وتحتاج بقاء التطبيق مفتوحًا. لا تتضمن النسخة الحالية مراقبة الحافظة بالخلفية أو site grabber أو تنزيل التورنت/HLS. تكامل المتصفح مقتصر على الامتداد الموضح أعلاه لإرسال عنوان صفحة أو رابط يدوي؛ ولا يتجاوز التطبيق تسجيل الدخول أو قيود الوصول أو حماية المحتوى.

## التحقق

- `npm test` — يبني TypeScript ويشغّل اختبارات محرك التنزيل، والاستئناف، والإعدادات، والتحقق من رابط تسليم الامتداد.
- `npm run check` — يبني TypeScript ويتحقق من صياغة ملفات JavaScript.
- `npm run build:win` — ينشئ مثبت Windows محليًا.
- انشر إصدارًا على GitHub بدفع وسم `v1.1.0` لتشغيل بناء Windows ونشر مرفقات التحديث تلقائيًا عبر GitHub Actions.
